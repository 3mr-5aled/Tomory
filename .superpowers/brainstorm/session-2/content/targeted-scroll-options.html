Targeted Smooth Scroll Options

How should we trigger the scroll from the Hero button?

A

Context & Hook (Recommended)

We'll create a useLenis hook. This is the "cleanest" React way, allowing any component to precisely control the scroll with lenis.scrollTo('#story').

B

Custom Event Trigger

The Hero button dispatches a 'scroll-to-story' event, and the SmoothScroll component listens for it. Very decoupled, but slightly less flexible than a hook.

Implementation Preview (Option A)
// In ImmersiveHero.jsx
const { lenis } = useLenis();

const handleScroll = () => {
  lenis.scrollTo('#story', { duration: 2 });
}

<button onClick={handleScroll}>Scroll</button>
